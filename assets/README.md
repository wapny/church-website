# assets/

Все изображения и иконки из макета Figma лежат в этой папке, сайт ссылается на них по именам.

- Фото сохранены в формате WebP и уже сжаты (всего около 1,2 МБ), поэтому сайт грузится быстро.
- Кадрирование как в макете задано в `css/style.css`.
- Чтобы заменить фото, сохраните новый файл под тем же именем и в том же формате (WebP).
- Исходные файлы в полном размере остались у меня в рабочей папке; если они понадобятся, скажите.
- `history-mask.svg` сейчас не используется: в макете это сплошной прямоугольник, он ничего не меняет.
